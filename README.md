# Glouf website

Marketing site for Glouf — identify the original amid similarities. A technology by Blimp International Digital Services Limited.

## Pages
- `index.html` — Home
- `about.html` — About us
- `how-it-works.html` — How it works
- `manufacturers.html` — For manufacturers
- `verify.html` — Verify a product
- `blog.html` — Blog (3 starter articles)
- `signup.html` — Merchant sign-up form
- `faq.html` — FAQ
- `contact.html` — Contact

Each page is self-contained static HTML (no build step). Deploy the folder to any static host (GitHub Pages, Netlify, Vercel, cPanel).

## Before going live
- Replace phone number and office address placeholders on `contact.html`
- Confirm the contact email (`hello@glouf.com`)
- Connect the sign-up and contact forms to a form service if you don't want them to open the visitor's email app
